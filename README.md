# FtR-YPG

FtR-YPG is the online forum for the Young Philosophers' Group. It gives YPG members a dedicated place to write posts, discuss ideas, follow other members, comment in threads, vote on discussions, and keep conversations connected to the group's philosophy work.

The forum is run operationally by the FtR Project for YPG. Ownership, governance, permissions, and final control remain with YPG and the YPG Cabinet as described in the project license.

## Purpose

Young Philosophers' Group discussions often continue beyond meetings, classes, and informal conversations. FtR-YPG exists to make those discussions easier to keep, revisit, and develop. Members can start questions, refine arguments, compare views across topics, and build a shared record of thoughtful philosophical exchange.

The project is intended for YPG use. It is not public open-source software and does not grant general permission to copy, host, modify, distribute, or privately use the platform. See [LICENSE](LICENSE) for the full terms.

## Forum Topics

FtR-YPG supports discussion across major areas of philosophy, including metaphysics, ethics, logic, aesthetics, epistemology, politics, philosophy of mind, and philosophy of religion.
